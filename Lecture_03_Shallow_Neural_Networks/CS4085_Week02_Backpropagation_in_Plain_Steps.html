Our tiny network

Input → hidden layer → output

x→z[1]→a[1]→z[2]→ŷ

The network has four sets of parameters to learn:

W[1], b[1] connect the input to the hidden layer.
W[2], b[2] connect the hidden layer to the output.

n0 = input features, n1 = hidden units, n2 = output units (here n2 = 1, for yes/no classification).

Shapes

Know the size of every matrix

Most bugs in neural network code are shape bugs. Rule of thumb: W[l] has shape (units in this layer, units in previous layer).

ParameterShapeIn our pictureMeaning
W[1]n1 × n04 × 3one row of weights per hidden unit
b[1]n1 × 14 × 1a column vector, one bias per hidden unit
W[2]n2 × n11 × 4weights from hidden units to the output
b[2]n2 × 11 × 1a single number for one output

Each gradient has the same shape as its parameter: dW[1] is n1 × n0, db[1] is n1 × 1, and so on.

Forward propagation · left to right

Four equations make the prediction

1Z[1] = W[1]X + b[1]weighted sum
2A[1] = g[1](Z[1])hidden activation
3Z[2] = W[2]A[1] + b[2]weighted sum
4Ŷ = A[2] = σ(Z[2])sigmoid → probability

Then compare the prediction ŷ with the true answer y using the loss L(ŷ, y).

The network has made its prediction. Now we know how wrong it is. The question is: which weights caused this error, and by how much?

Measuring the error

The cost: average loss over m examples

JJ(W[1],b[1],W[2],b[2]) = (1/m) Σi=1..m L(ŷ(i), y(i))
LL(ŷ, y) = −[ y·log ŷ + (1−y)·log(1−ŷ) ]binary cross-entropy, same as logistic regression

ŷ is just A[2]

The prediction is the output of the last layer, a probability between 0 and 1.

Small J = good predictions

If y = 1 and ŷ = 0.99, the loss is tiny. If ŷ = 0.01, the loss is large. Training means pushing J down.

Step 1 · start from the error

The answer is y = 1, but the network says ŷ = 0.3

Something in the network needs to change. But there are many weights: W[1], W[2], … So for each one we ask:

“If I change this weight a tiny bit, does the loss go up or down?”

That question is a derivative: ∂L∂W

The gradient tells us the direction and strength of the blame.

Large gradientThis parameter strongly affects the error.
Small gradientThis parameter has little effect.

Notation

What does the “d” mean?

We write dZ[l], dW[l], db[l]. The d simply means: how sensitive is the loss to this quantity?

dW[2]  means  ∂L∂W[2]

In plain words

dW[2] tells us how much W[2] contributed to the error.

You can introduce the words “partial derivative” later, once the meaning is clear.

Backward · the output layer

Prediction minus truth

With sigmoid + binary cross-entropy, the output error has a beautifully simple form:

1dZ[2] = A[2] − Y = Ŷ − Ythe backward signal
ŷ = 0.9, y = 1
−0.1
ŷ = 0.1, y = 1
−0.9

Close to the right answer → small signal. Far from it → large signal.

At the output layer, the backward signal is basically: prediction minus truth.

Backward · output layer parameters

Who connected the hidden layer to the output?

2dW[2] = (1/m) dZ[2] A[1]Tblame for the hidden → output weights
3db[2] = (1/m) Σ dZ[2]blame for the output bias

What dW[2] asks

How much did the connection between the hidden neurons and the output contribute to the error? A weight gets more blame when the hidden neuron feeding it was strongly active.

No need to memorise yet

These three lines are exactly gradient descent for logistic regression. The output layer is a logistic regression sitting on top of the hidden layer.

Backward · the hidden layer

Propagate the blame one layer back

a. Send the error back through the weights

dA[1] = W[2]T dZ[2]

The output layer sends the error information back to the hidden neurons. A neuron with a big weight to the output gets a bigger share.

b. Account for the activation

dZ[1] = dA[1] ⊙ g′(Z[1])

⊙ is element-wise. A neuron whose activation is flat (small g′) lets little error pass. For tanh, g′(z) = 1 − a².

5dW[1] = (1/m) dZ[1] XT
6db[1] = (1/m) Σ dZ[1]now every parameter has a gradient

First we send the error backward through the weights. Then we ask how much the activation function allowed that error to pass.

Backward propagation · all together

Six equations share the blame

1dZ[2] = A[2] − Youtput error
2dW[2] = (1/m) dZ[2] A[1]T
3db[2] = (1/m) Σ dZ[2]
4dZ[1] = W[2]TdZ[2] ⊙ g′(Z[1])hidden error
5dW[1] = (1/m) dZ[1] XT
6db[1] = (1/m) Σ dZ[1]

Backpropagation distributes responsibility for the final error backward through the network.

Mathematically, this “responsibility” is measured with gradients and the chain rule.

The chain rule, gently

Follow the path from W[1] to the loss

W[1] affects Z[1], which affects A[1], which affects Z[2], which affects L. To know how W[1] affects L, we follow the whole path:

W[1]→Z[1]→A[1]→Z[2]→L

The chain rule multiplies the effect of each link:

∂L∂W[1] = ∂L∂Z[2] · ∂Z[2]∂A[1] · ∂A[1]∂Z[1] · ∂Z[1]∂W[1]

Backpropagation is an efficient implementation of the chain rule.

For any layer l

The four equations to remember

dZ[l] = dA[l] ⊙ g′[l](Z[l])dZ → the error at this layer
dW[l] = (1/m) dZ[l] A[l−1]TdW → how the weights contributed to the error
db[l] = (1/m) Σ dZ[l]db → how the biases contributed to the error
dA[l−1] = W[l]T dZ[l]dA → send the error to the previous layer

Repeat these four lines from the last layer back to the first. The meaning is more useful than memorising the formulas.

The complete story

One training cycle

  1. 1Forward propagation → make prediction ŷ
  2. 2Compute loss → how wrong are we?
  3. 3Backpropagation → compute dW and db
  4. 4Gradient descent → update W and b
  5. 5Repeat until the cost stops falling
W := W − α · dW
b := b − α · dbα = learning rate, the step size

Common confusion

Backpropagation does not update the weights. It computes the gradients. Gradient descent uses those gradients to update the weights.

Initialise weights randomly, not with zeros. If all weights start equal, every hidden unit learns the same thing.

Try it with real numbers

One neuron, one example, one step

Take x = 2, true label y = 1, starting weight w = 0.5, bias b = 0, learning rate α = 0.1.

forward · z = w·x + b1.000
forward · ŷ = σ(z)0.731
backward · dz = ŷ − y−0.269
backward · dw = dz·x−0.538
backward · db = dz−0.269
update · w − α·dw0.554
update · b − α·db0.027
new prediction ŷ0.757

The prediction moved from 0.731 to 0.757, closer to the true answer 1. Repeat this thousands of times and the network learns.

In NumPy

The whole thing in a few lines

# forward
Z1 = W1 @ X + b1
A1 = np.tanh(Z1)
Z2 = W2 @ A1 + b2
A2 = 1 / (1 + np.exp(-Z2))

# backward
dZ2 = A2 - Y
dW2 = (1/m) * dZ2 @ A1.T
db2 = (1/m) * np.sum(dZ2, axis=1, keepdims=True)
dA1 = W2.T @ dZ2
dZ1 = dA1 * (1 - A1**2)          # tanh derivative
dW1 = (1/m) * dZ1 @ X.T
db1 = (1/m) * np.sum(dZ1, axis=1, keepdims=True)

# update (gradient descent)
W1 -= alpha * dW1;  b1 -= alpha * db1
W2 -= alpha * dW2;  b2 -= alpha * db2
