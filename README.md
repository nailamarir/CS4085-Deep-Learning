## Using the slide decks

Each deck is a **single self-contained HTML file**. Open it in any browser — no build
step, no dependencies.

| Action | Key |
|---|---|
| Next / previous slide | `→` `←` `Space`, or click the right/left half of the screen |
| Fullscreen | `F` |
| First / last slide | `Home` / `End` |
| Reveal the answer on a question slide | `A` |

Decks print to PDF at 1600×900 (⌘P / Ctrl-P).
