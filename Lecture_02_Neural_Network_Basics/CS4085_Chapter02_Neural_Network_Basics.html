This chapter

How a network is
actually computed

Chapter 1 said the model is corrected until its error is small. This chapter shows exactly how that correction is computed.

We use logistic regression to carry the ideas, because it is the smallest thing that has every piece a neural network has — and nothing it does not.

Two techniques that matter

What to watch for

01

No for-loops

vectorisation

You are used to looping over m training examples. When you implement a neural network you want to process the whole training set at once, with no explicit loop.

02

Forward, then
backward

two passes

Computation is organised as a forward pass that produces the prediction, then a backward pass that computes how to change the parameters.

Binary classification · the problem

One image in, one bit out

The output y is a single bit. That is what makes this binary classification.

Binary classification · the input

An image is three matrices

One matrix per colour channel, each holding the pixel intensities. Drawn here as a small excerpt — the real matrices are 64 × 64.

Binary classification · the feature vector

Unroll the pixels into one column

nx = 64 × 64 × 3 = 12,288 n_x is the dimension of the input feature vector. Often just written n.
Part 2
Notation
Used for the rest of the course.
Notation · one example, then all of them

A pair, and m of them

(x, y)    x ∈ ℝnx,   y ∈ {0, 1} one training example: a feature vector and a label that is 0 or 1
{ (x⁽¹⁾, y⁽¹⁾), (x⁽²⁾, y⁽²⁾), … , (x⁽ᵐ⁾, y⁽ᵐ⁾) } the whole training set — m examples, indexed by round-bracket superscripts

m is the number of training examples. Where it matters, write mtrain and mtest.

Notation · the matrix X

Stack examples in columns

Some books stack examples in rows. Do not. Columns make the implementation much easier — and this is the convention for the whole course.

Notation · the matrix Y

Stack the labels the same way

The rule to remember: data belonging to different training examples goes in different columns — for x, for y, and for everything later.

Part 3
Logistic
Regression
Logistic regression · the goal

We want a probability

ŷ = P( y = 1 | x ) "given this picture, what is the chance it is a cat?"

So ŷ must lie between 0 and 1.

Parameters: w ∈ ℝnx  and  b ∈ ℝ — a vector and a single number.

Logistic regression · the obvious idea fails

A straight line is not
a probability

ŷ = wᵀx + b this is linear regression — and it is the wrong tool here

wᵀx + b can be far bigger than 1, and it can be negative. Neither makes sense as a chance.

We need to squash it into [0, 1].

The sigmoid
does the
squashing
ŷ = σ(z)
z = wᵀx + b
The sigmoid function

Why it behaves that way

σ(z) = 1 / (1 + e−z)
IF z IS LARGE

σ(z) ≈ 1

e−z becomes tiny, so we get 1 / (1 + almost 0) — which is almost 1.

IF z IS VERY NEGATIVE

σ(z) ≈ 0

e−z becomes huge, so we get 1 / (1 + huge) — which is almost 0.

Your job when you train: find w and b so that ŷ is a good estimate of the chance that y = 1.

A note on notation

Keep w and b separate

Some courses fold the bias into the parameter vector by adding a feature x₀ = 1 and writing ŷ = σ(θᵀx), with θ₀ playing the role of b.

We do not use that convention in this course.

When you implement neural networks it is easier to keep the weight vector w and the bias b as two separate things. If you have never seen the θ notation, you can safely ignore this slide.

Question

What are the parameters
of logistic regression?

  • Aw, an identity vector, and b, a real number.
  • Bw and b, both real numbers.
  • Cw and b, both nx-dimensional vectors.
  • Dw, an nx-dimensional vector, and b, a real number.

D. One weight per input feature — so w ∈ ℝnx — and a single bias b ∈ ℝ shared by the whole unit.

Part 4
Loss and Cost
Loss · the first idea does not work

Squared error gives a bumpy surface

You could use ½(ŷ − y)², but for logistic regression it makes the optimisation non-convex — gradient descent can get stuck in a local minimum.

Loss · on a single example

The logistic loss

L(ŷ, y) = − ( y log ŷ + (1 − y) log(1 − ŷ) ) convex, so gradient descent will find the global minimum
IF y = 1

L = − log ŷ

The second term vanishes. To make the loss small you need log ŷ large — so ŷ must be close to 1.

IF y = 0

L = − log(1 − ŷ)

The first term vanishes. To make the loss small you need log(1 − ŷ) large — so ŷ must be close to 0.

Loss and cost are not the same thing

One example, or all of them

LOSS

L(ŷ, y)

a single training example

How well you did on one example.

COST

J(w, b)

the whole training set

How well your parameters are doing overall. This is what training minimises.

J(w, b) = (1/m) Σi=1..m L( ŷ⁽ⁱ⁾, y⁽ⁱ⁾ )
= − (1/m) Σi=1..m [ y⁽ⁱ⁾ log ŷ⁽ⁱ⁾ + (1 − y⁽ⁱ⁾) log(1 − ŷ⁽ⁱ⁾) ] the same thing with L written out in full — the minus sign is outside everything
Question

What is the difference between the
cost function and the loss function?

  • AThe cost function computes the error for a single training example; the loss function is the average of the cost functions of the entire training set.
  • BThe loss function computes the error for a single training example; the cost function is the average of the loss functions of the entire training set.
  • CThey are different names for the same function.

B. L is per-example; J averages it over all m. A is the two swapped, and C ignores the averaging entirely.

Part 5
Gradient
Descent
Gradient descent · why convexity matters

One bowl, one bottom

Because J(w, b) is convex, it does not matter much where you start — you reach the same bottom. That is a big reason this cost function was chosen.

Gradient descent · the update

Repeat until it stops
getting better

w := w − α · ∂J/∂w

b := b − α · ∂J/∂b α is the learning rate — how big a step to take

The derivative is the slope: it says which way is downhill. The minus sign means you move against the slope, and so downwards.

In code, ∂J/∂w is usually written dw, and ∂J/∂b as db.

Putting it together

Forward pass, then backward pass

Every training step is these two passes. Forward produces the prediction and the loss; backward produces the gradients that update w and b.

Chapter 2 · recap

What to carry forward

  • 01An image becomes a feature vector of length nx = 12,288.
  • 02Stack training examples in columns: X is nx × m, Y is 1 × m.
  • 03Logistic regression outputs a probability: ŷ = σ(wᵀx + b).
  • 04The sigmoid squashes any real number into (0, 1).
  • 05Loss is one example; cost J(w,b) is the average over all m.
  • 06The logistic loss is used because it is convex.
  • 07Gradient descent steps downhill on J using the slope.
