Depth · the definition

What is a deep neural network?

Count the hidden layers plus the output layer — the input is layer 0 and is not counted. "Deep" is a spectrum: the more hidden layers, the deeper the network.

Notation · naming every part

Deep neural network notation

  • Lthe number of layers here L = 4 — hidden layers plus the output
  • n[l]the number of units in layer l n[1]=5, n[2]=5, n[3]=3, n[4]=n[L]=1
    n[0] = nx = 3 input features
  • a[l]the activations in layer l a[l] = g[l](z[l])
  • W[l], b[l]the weights and bias used to compute z[l]
  • a[0], a[L]the two ends of the chain x = a[0]  and  ŷ = a[L]
Forward propagation · one example x

Forward propagation in a deep network

layer 1z[1] = W[1]a[0] + b[1]a[1] = g[1](z[1])
layer 2z[2] = W[2]a[1] + b[2]a[2] = g[2](z[2])
layer 3z[3] = W[3]a[2] + b[3]a[3] = g[3](z[3])
layer 4z[4] = W[4]a[3] + b[4]a[4] = g[4](z[4]) = ŷ

Start from x = a[0]. Each layer takes the previous layer's activations, and the last one gives the prediction.

Forward propagation · all m examples at once

Vectorised: stack the examples as columns

layer 1Z[1] = W[1]A[0] + b[1]A[1] = g[1](Z[1])
layer 2Z[2] = W[2]A[1] + b[2]A[2] = g[2](Z[2])
layer 3Z[3] = W[3]A[2] + b[3]A[3] = g[3](Z[3])
layer 4Z[4] = W[4]A[3] + b[4]Ŷ = g[4](Z[4]) = A[4]

Same equations, capital letters. X = A[0], and every Z[l], A[l] now holds all m examples side by side.

Forward propagation · the general rule

One loop over the layers

FOR ANY LAYER l · HERE L = 4

A[0] = X
for l = 1 … L:
    Z[l] = W[l]A[l−1] + b[l]
    A[l] = g[l](Z[l])
Ŷ = A[L]

The four layer-by-layer lines from before collapse into two lines inside a loop.

We removed the loop over examples by vectorising. This loop over layers stays: layer l cannot start until layer l−1 is finished, so there is nothing to vectorise.

Loop over layers: fine. Loop over examples: never.

Why deep · the intuition

Intuition about deep representation

Early layers detect simple things in small patches, like edges. Later layers combine them into parts, then whole faces: complex things over large regions.

Why deep · the same idea for audio

From sound waves to sentences

Each layer builds on the one before. Short slices of sound become phonemes, phonemes become words, and words become sentences. Depth lets the network compose simple features into complex ones.

Why deep · the formal argument

Circuit theory and deep learning

Informally: there are functions you can compute with a “small” L-layer deep neural network that shallower networks require exponentially more hidden units to compute.

The classic example · parity

y = x1 XOR x2 XOR x3 XOR … XOR xn

y is 1 when an odd number of the n input bits are 1.
Flip any single bit and the answer flips.

1011three 1s → y = 1
1001two 1s → y = 0
Why deep · computing XOR of n bits two ways

Deep builds a tree; shallow builds a wall

DEEP · MANY LAYERS

O(log n) layers

Pair up the bits and XOR them, then pair up the results, like a tournament bracket. Only about n − 1 XOR gates in total.

SHALLOW · ONE HIDDEN LAYER

O(2ⁿ) units

With a single hidden layer the network has to cover every possible combination of the n inputs: an exponentially large layer.

Building blocks · zoom in on one layer

Forward and backward functions

FORWARD FUNCTION · USES W[l], b[l]

inputa[l−1]
outputa[l]  + cache z[l]

z[l] = W[l]a[l−1] + b[l]
a[l] = g[l](z[l])

BACKWARD FUNCTION · USES W[l], b[l]

inputda[l]  + cache z[l]
outputda[l−1],  dW[l],  db[l]

da[l−1] is passed back to the previous layer. dW[l] and db[l] are what gradient descent needs.

Building blocks · one layer, two boxes

The cache links forward and backward

Forward stores z[l] in the cache instead of throwing it away. Backward reads it to compute dz[l], then returns da[l−1] to the layer before and dW[l], db[l] for the update. Red arrows run backward.
