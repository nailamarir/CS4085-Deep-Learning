Part 2
Regularisation
The first fix for high variance.
Regularisation · logistic regression

Penalise large weights

J = (1/m) Σ ℒ(ŷ, y) + (λ/2m) ‖w‖²

  • ‖w‖² = w₁² + w₂² + … = wᵀw
  • λ is a hyperparameter — tune it on dev
Regularisation · the effect

Large weights get pushed down

The bigger the weight, the bigger the penalty.

Regularisation

L2 or L1?

L2: (λ/2m) Σ wj²

L1: (λ/2m) Σ |wj|

L1 makes weights zero. In practice, use L2.

Regularisation · L2 vs L1, the picture

Circle vs diamond

The diamond’s corners sit on the axes → some weights become exactly 0.

Regularisation · neural network

Penalise every layer

+ (λ/2m) Σl ‖W[l]‖F²

Regularisation · backprop

One extra term in dW

dW[l] = (backprop) + (λ/m) W[l]

Everything else in backprop stays the same.

Regularisation · the update

Why it’s called weight decay

W[l] := (1 − αλ/m) W[l] − α (backprop)

Why regularisation works · 1

Big λ → smaller network

  • λ large → W ≈ 0
  • Many units do almost nothing
  • Simpler model → less overfitting
Why regularisation works · 2

Small weights → nearly linear

  • λ ↑ → W ↓ → z small
  • tanh is linear near 0
  • A linear network can’t overfit wiggles
Regularisation · debugging tip

Plot the full cost

J = (1/m) Σ ℒ + (λ/2m) Σ ‖W‖²

Include the λ term when you check J.

Dropout

Randomly drop units

A different random network for every training example.

Dropout · in code

Inverted dropout

d3 = np.random.rand(*a3.shape) < keep_prob
a3 = a3 * d3
a3 = a3 / keep_prob

Layer 3, keep_prob = 0.8. Next slide: what each line does.

Dropout · step by step

Mask, multiply, rescale

Dropping 20% makes a3 smaller → ÷ 0.8 restores its size.

Dropout · test time

No dropout at test time

  • Use all units
  • No random mask
  • No ÷ keep_prob

Predictions must be the same every time.

Dropout · why it works

Can’t rely on one feature

Any input may vanish → spread the weight out → smaller weights, like L2.

Dropout · tuning

keep_prob can differ by layer

Big layers → lower keep_prob. Small layers → 1.0.

Dropout · one downside

J is no longer well defined

  • Dropout off → check J
  • Then dropout on
Question

keep_prob goes from 0.5 to 0.6.
What happens?

  • AMore regularisation
  • BLess regularisation
  • CMore layers
  • DNothing

B. Fewer units are dropped, so the regularising effect is weaker.

Normalising inputs

Normalise the inputs

STEP 1

x := x − μ

STEP 2

x := x / σ

Normalising inputs

Use the same μ and σ

Compute μ, σ on training data only. Reuse them everywhere.

Normalising inputs · why

Round bowls are easier

Features on the same scale → faster gradient descent.

Vanishing / exploding gradients

Deep = many multiplications

ŷ = W[L] ⋯ W[2] W[1] x

Vanishing / exploding gradients

A little above or below 1

W = 1.5 · I

Explodes

W = 0.5 · I

Vanishes

Gradients do the same → training breaks.

Weight initialisation

More inputs → smaller weights

  • z adds up n terms
  • Big n → small w
  • Var(w) = 2/n for ReLU
Weight initialisation · in code

Scale the random weights

W[l] = np.random.randn(shape) * np.sqrt(2 / n[l−1])
ReLU√(2 / n[l−1])He
tanh√(1 / n[l−1])Xavier

Gradient checking · step 1

Approximate a derivative

[f(θ+ε) − f(θ)] / ε

(1.01³ − 1) / 0.01
= 3.0301

True answer: 3 · error 0.03

Gradient checking · step 2

Two-sided is better

[f(θ+ε) − f(θ−ε)] / 2ε

(1.01³ − 0.99³) / 0.02
= 3.0001

True answer: 3 · error 0.0001

Gradient checking · step 3

Flatten everything into θ

Do the same with dW, db → dθ. Is dθ really the gradient of J(θ)?

Gradient checking · step 4

Compare, one entry at a time

dθapprox[i] = [J(θi+ε) − J(θi−ε)] / 2ε

check: ‖dθapprox − dθ‖ / (‖dθapprox‖ + ‖dθ‖)

Gradient checking · read the result

Is backprop correct?

Gradient checking · tips

Grad check rules

  • Debug only — not in training
  • If it fails, find the bad component
  • Include the λ term
  • Turn dropout off
  • Run at random init
Summary

Remember

  • Train error → bias; gap → variance
  • Bias → bigger net. Variance → data or regularise
  • L2 and dropout fight overfitting
  • Normalise inputs, scale initial weights
  • Grad check to debug backprop
