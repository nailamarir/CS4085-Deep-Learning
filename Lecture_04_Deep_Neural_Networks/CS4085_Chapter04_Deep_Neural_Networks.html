Chapter 3 built a network with one hidden layer. Nothing new is needed to go deeper — you repeat the same block.

What is new: keeping the dimensions straight, understanding why depth helps, and separating the things you learn from the things you choose.

Depth · the definition

How deep is deep?

Shallow is one or two layers. Deep is three or more. It is a spectrum, not a category — "deep" just means many hidden layers.

Counting on a real network

Four layers, because the input layer does not count. The vector n is [3, 5, 5, 3, 1] — length L+1.

Notation · what lives in memory

Four things to keep

  • na vector of shape (1, L+1) — the neuron count of every layer, including the input.
  • ga vector of shape (1, L) — the activation function of each layer. The input layer has none.
  • Wa list of matrices, each a different shape, set by the neuron counts of the current and previous layer.
  • ba list of vectors, each shaped by the current layer alone.

W and b cannot be one array, because every layer has a different shape. In code they are usually a dictionary keyed by layer number.

Part 2
Forward
Propagation
Forward propagation · the general rule

Two lines, any layer

ONE INPUT

a single example

z⁽ˡ⁾ = W⁽ˡ⁾a⁽ˡ⁻¹⁾ + b⁽ˡ⁾
a⁽ˡ⁾ = g⁽ˡ⁾(z⁽ˡ⁾)

lower case — one column at a time

m INPUTS

the whole batch

Z⁽ˡ⁾ = W⁽ˡ⁾A⁽ˡ⁻¹⁾ + b⁽ˡ⁾
A⁽ˡ⁾ = g⁽ˡ⁾(Z⁽ˡ⁾)

upper case — all m examples at once

This is identical to Chapter 3, with the specific layer numbers replaced by l. Writing it this way is what lets one piece of code serve every layer.

Forward propagation · the exception to the rule

This for-loop is fine

A⁽⁰⁾ = X
for l = 1 to L:
  Z⁽ˡ⁾ = W⁽ˡ⁾A⁽ˡ⁻¹⁾ + b⁽ˡ⁾
  A⁽ˡ⁾ = g⁽ˡ⁾(Z⁽ˡ⁾)

We have spent two chapters removing loops. This one stays.

You cannot compute layer 3 before layer 2 is finished — the layers are genuinely sequential. There is no way to vectorise across layers, and no need to: the loop runs L times, not m times.

Loop over layers: fine. Loop over examples: never.

Part 3
Matrix
Dimensions
Where most bugs live.
Dimensions · the debugging method

Use a pencil
and paper

When your code throws a shape error — and it will — the fastest fix is to write the dimensions out by hand, layer by layer.

Most deep learning bugs are not subtle mathematical errors. They are a matrix that is the wrong way round.

Get into the habit now, while the networks are small enough to check in a few lines.

Dimensions · the complete reference

Every shape in the network

QuantityShapeWhy
W⁽ˡ⁾(n⁽ˡ⁾, n⁽ˡ⁻¹⁾)maps n⁽ˡ⁻¹⁾ numbers in to n⁽ˡ⁾ numbers out — read it right to left

The rule behind half this table: a derivative has the same shape as its variable.

Dimensions · checking a multiply

The inner dimensions cancel

(n⁽ˡ⁾, n⁽ˡ⁻¹⁾) × (n⁽ˡ⁻¹⁾, m) = (n⁽ˡ⁾, m) — the inner n⁽ˡ⁻¹⁾ cancels. If it does not cancel, your shapes are wrong.

Question

n⁽²⁾ = 5, n⁽³⁾ = 4, and m = 1000.
What is the shape of dW⁽³⁾?

  • A(4, 1000) — same as Z⁽³⁾.
  • B(4, 5) — same as W⁽³⁾.
  • C(5, 4) — the transpose.
  • D(4, 1) — same as b⁽³⁾.

B. A gradient always has the same shape as its variable, and W⁽³⁾ : (n⁽³⁾, n⁽²⁾) = (4, 5). Note that m never appears in a W or b shape — only in Z, A and their gradients.

Part 4
Why Deep
Representations?
Why deep · the intuition

Simple features first,
complex ones later

Each layer builds a relationship with the layer before it — from simple to complex. Researchers think this resembles how brains process information.

Why deep · the formal argument

Circuit theory:
depth buys you size

There are functions a small L-layer network computes easily, that a network with one hidden layer needs exponentially many neurons to compute.

DEEP

O(log n)

Layers of pairwise XOR, combined like a tournament bracket. Depth grows with log n, and the total neuron count stays small.

SHALLOW

O(2ⁿ)

With one hidden layer you must enumerate every possible configuration of the n inputs — exponentially many hidden units.

The classic example is computing the XOR of n input bits: a tree of depth log n, versus a single layer that must cover all 2ⁿ cases.

Why deep · the practical warning

Do not start
with 20 layers

When you begin a new application, the right move is almost always the simplest thing that could work.

  • 01Try logistic regression first. It is fast, and it gives you a baseline number.
  • 02Then a shallow network — one or two hidden layers.
  • 03Then add depth, and measure whether it actually helps.

The number of layers is a hyperparameter like any other — something you tune, not something you guess once.

Building
Blocks
Building blocks · one layer

One layer, two boxes

The cache is the trick. Backward propagation needs Z⁽ˡ⁾ to evaluate g′, so forward propagation stores it instead of throwing it away.

Building blocks · the whole network

Stack the blocks

Building blocks · forward, for layer l

The forward block

Input  A⁽ˡ⁻¹⁾
  Z⁽ˡ⁾ = W⁽ˡ⁾A⁽ˡ⁻¹⁾ + b⁽ˡ⁾
  A⁽ˡ⁾ = g⁽ˡ⁾(Z⁽ˡ⁾)
Output A⁽ˡ⁾, cache(Z⁽ˡ⁾)

Two lines of arithmetic, plus one line that saves Z⁽ˡ⁾ for later. In practice you cache W⁽ˡ⁾ and A⁽ˡ⁻¹⁾ too, since the backward block needs them as well.

Building blocks · backward, for layer l

The backward block

Input  dA⁽ˡ⁾, caches
  dZ⁽ˡ⁾ = dA⁽ˡ⁾ ∗ g′⁽ˡ⁾(Z⁽ˡ⁾)
  dW⁽ˡ⁾ = (dZ⁽ˡ⁾ A⁽ˡ⁻¹⁾ᵀ) / m
  db⁽ˡ⁾ = sum(dZ⁽ˡ⁾) / m  # axis=1, keepdims=True
  dA⁽ˡ⁻¹⁾ = W⁽ˡ⁾ᵀ dZ⁽ˡ⁾
Output dA⁽ˡ⁻¹⁾, dW⁽ˡ⁾, db⁽ˡ⁾

Same six-equation shape as Chapter 3, written once for a general layer. The output dA⁽ˡ⁻¹⁾ is the input to the next backward block — that is what chains them together.

Do not forget keepdims=True — without it NumPy collapses db into a rank-1 array and the shapes silently break.

Building blocks · the first domino

Starting the
backward pass

The backward chain needs a value to begin with: dA⁽ᴸ⁾, the derivative of the loss with respect to the final activation.

dA⁽ᴸ⁾ = −(y/a) + (1−y)/(1−a) the derivative of the logistic loss from Chapter 2

Feed that into the layer-L backward block, and every other gradient follows from the chain of dA⁽ˡ⁻¹⁾ outputs.

In practice layer L usually combines this with the sigmoid derivative straight into dZ⁽ᴸ⁾ = A⁽ᴸ⁾ − Y — the same shortcut as Chapter 3.

Part 6
Parameters vs
Hyperparameters
Parameters · the distinction

What is learned,
what is chosen

PARAMETERS

W and b

learned by gradient descent

The network finds these itself. You never set them by hand — you only initialise them and let the gradients do the rest.

W⁽¹⁾, b⁽¹⁾, W⁽²⁾, b⁽²⁾, … W⁽ᴸ⁾, b⁽ᴸ⁾

HYPERPARAMETERS

everything else

chosen by you

These control the algorithm that learns W and b — so they ultimately control what W and b end up being.

α, iterations, L, n⁽ˡ⁾, choice of g⁽ˡ⁾

In the early days of the field the learning rate was often called a parameter. It is a hyperparameter — and now everyone calls it that.

Parameters · the ones you will tune

The list, so far

  • αthe learning rate — how big a step gradient descent takes.
  • Nthe number of iterations of gradient descent.
  • Lthe number of hidden layers.
  • nthe number of hidden units in each layer.
  • gthe choice of activation function per layer.

There is no formula for any of these. You try values, measure, and try again — applied deep learning is an empirical process.

The next course adds more: momentum, mini-batch size, regularisation terms — and a systematic way to search over them.

Question

Which of these is a parameter,
not a hyperparameter?

  • AThe learning rate α.
  • BThe number of hidden layers L.
  • CThe weight matrix W⁽²⁾.
  • DThe choice of activation function g⁽¹⁾.

C. W and b are the only parameters — they are learned by gradient descent. Everything else on this list you choose, and your choices control how W and b are learned.

Part 7
What About
the Brain?
The brain · where the analogy comes from

One unit, one neuron

Both take several inputs, combine them, and produce one output. That resemblance is real — and it is also where the similarity runs out.

The brain · the honest version

An oversimplified
explanation

"It is like the brain" is an easy thing to say and a hard thing to defend.

  • 01No one today understands how a single biological neuron works.
  • 02No one knows exactly how many neurons a human brain has.
  • 03A logistic unit is a very simplistic stand-in for something far more complicated.

What deep learning is actually good at: learning flexible, complex functions that map X to Y — supervised learning.

Computer vision has drawn more genuine inspiration from the brain than the other subfields. The convolutional networks of Chapter 6 are the closest thing we have — and even that is a loose analogy.

Chapter 4 · recap

What to carry forward

  • 01Shallow is 1–2 layers; deep is 3 or more. L counts layers, input excluded.
  • 02Forward propagation is one rule: Z⁽ˡ⁾ = W⁽ˡ⁾A⁽ˡ⁻¹⁾ + b⁽ˡ⁾, applied in a loop over layers.
  • 03A loop over layers is fine; a loop over examples is not.
  • 04W⁽ˡ⁾ is (n⁽ˡ⁾, n⁽ˡ⁻¹⁾), b⁽ˡ⁾ is (n⁽ˡ⁾, 1), Z⁽ˡ⁾ and A⁽ˡ⁾ are (n⁽ˡ⁾, m).
  • 05A gradient has the same shape as the thing it differentiates.
  • 06Depth builds simple features into complex ones — and buys an exponential saving in width.
  • 07Each layer is a forward block and a backward block, joined by a cache.
  • 08W and b are parameters. Everything else you pick is a hyperparameter.
