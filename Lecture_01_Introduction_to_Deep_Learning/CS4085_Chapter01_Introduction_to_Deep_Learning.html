Machine Learning · in plain words

Teaching a computer
without programming it

We use examples to train computers to do tasks that would be very difficult to write rules for.

Machine Learning · the classic definition

A program learns from experience E
at some task T, measured by performance P,
if its P at T improves with E.

Tom Mitchell, 1997

E

Experience

what it sees

Thousands of past houses, each with its real selling price.

T

Task

what it must do

Guess the price of a house it has never seen.

P

Performance

how we score it

How close its guesses are to the real prices.

Show it more houses and its guesses get better — that is learning.

Supervised learning · how it actually works

Fit, measure, correct — repeat

The model is never told the rule. It is corrected until its error is small — and the rule is what remains.

Component 01 · Dataset

What the model learns from

m examples. Each is a pair (x⁽ⁱ⁾, y⁽ⁱ⁾) — the feature we measure and the answer we want.

Component 02 · Model and its Parameters

The shape we allow, and the knobs we turn

ŷ = wx + b The model is the whole family of straight lines. The parameters w and b choose one of them.
Component 03 · The Cost Function

One number for how wrong we are

J(w,b) = (1/m) Σ (ŷ⁽ⁱ⁾ − y⁽ⁱ⁾)² Square each gap so misses in both directions count, then average. Small J means a good fit.
Component 04 · The Learning Algorithm

Walk downhill until the cost stops falling

w := w − α · dJ/dw Gradient descent. The slope says which way is downhill; α says how big a step to take.

House prices · the same four components

A line, a squared error,
and a step downhill

ComponentFor house prices
Datasetm = 6 pairs (size, price)
Modelŷ = wx + b  — a straight line
Cost functionJ(w,b) = (1/m) Σ (ŷ⁽ⁱ⁾ − y⁽ⁱ⁾)² — mean squared error
Learning algorithmgradient descent on w and b
One correction step

The error tells you
which way to move

start   w = 2000, b = 50000

example   x = 100 m²,   y = 300,000

predict   ŷ = 2000(100) + 50000 = 250,000

error     ŷ − y = 250,000 − 300,000 = −50,000 Negative error means the prediction was too low — so w must increase.

Nudge w to 2050 and the next prediction is 255,000. Still low, but closer. Repeat across thousands of houses.

The training loop

Nobody wrote the pricing rule. It was adjusted into existence, one example at a time.

Where deep learning wins

Structured vs. unstructured data

STRUCTURED

Rows and columns

Each feature already has a clear meaning: size, age, price, click.

Classical ML is strong here — gradient boosting often still wins.
UNSTRUCTURED

Pixels, audio, text

No individual number means anything on its own.

This is where deep learning changed everything.

Humans are excellent at unstructured data. Getting computers to match that is what made deep learning famous.

Why is deep learning taking off now?
Scale
changed everything
The ideas are decades old. The data, the hardware and the algorithms are not.
Scale drives deep learning progress

Traditional algorithms plateau. Bigger networks keep improving — but only if you feed them enough data.
